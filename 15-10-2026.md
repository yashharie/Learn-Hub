# Daily Technical Learning Notes

**Date:** 15 October 2026  
**Session type:** Technical knowledge sharing  

Today, we shared knowledge about five technical fields: UI/UX Design, Software Architecture, AI Engineering, Quality Assurance (QA) Engineering, and DevOps Engineering.

## 1. UI/UX Designer
UI/UX designers create digital products that are visually appealing, accessible, and easy to use.

- **UI:** Focuses on layouts, colours, buttons, fonts, and visual design.
- **UX:** Focuses on usability and user experience.

**Responsibilities:** User research, wireframes, prototypes, interface design, usability testing, and collaboration with developers.

**Tools:** Figma, FigJam, Canva, Adobe XD.

**Career paths:** UI Designer, UX Designer, Product Designer, UX Researcher.

## 2. Software Architecture
Software architecture defines the structure of a software system and how its components communicate.

**Main components:**
- **Frontend:** User interface.
- **Backend:** Application logic.
- **Database:** Data storage and management.

**Architecture styles:** Monolithic, Layered, Microservices, Client–Server, Event-Driven, and MVC.

**Benefits:** Maintainability, scalability, security, performance, and better teamwork.

## 3. AI Engineering
AI engineering focuses on building, deploying, and maintaining applications that use AI models.

**Key concepts:**
- Data engineering and model development.
- Retrieval-Augmented Generation (RAG).
- Prompt engineering.
- Embeddings and vector databases.
- AI agents and orchestration.
- MLOps, LLMOps, safety, and evaluation.

**Tools:** Python, Pandas, PyTorch, TensorFlow, FastAPI, Docker.

**Career paths:** AI Engineer, Machine Learning Engineer, Data Scientist.

## 4. QA Engineer
A Quality Assurance Engineer helps ensure software meets requirements and works correctly.

**Responsibilities:** Requirement analysis, test planning, test case creation, manual and automated testing, defect reporting, retesting, and regression testing.

**Types of testing:** Functional, integration, system, regression, API, performance, security, usability, and User Acceptance Testing (UAT).

**Tools:** Jira, Selenium, Playwright, Cypress, Postman, JMeter.

**Career paths:** QA Engineer, Test Automation Engineer, SDET, QA Lead.

## 5. DevOps Engineer
DevOps combines Development and Operations practices to automate software building, testing, deployment, monitoring, and maintenance.

**Key responsibilities:**
- Manage Git and GitHub workflows.
- Package applications using Docker.
- Automate builds and deployments using CI/CD.
- Manage cloud infrastructure.
- Monitor applications and troubleshoot errors.
- Protect credentials and deployment pipelines.

**Tools and concepts:**

| Category | Examples |
|---|---|
| Version control | Git, GitHub |
| Operating systems | Linux |
| Containers | Docker, Docker Compose |
| CI/CD | GitHub Actions |
| Cloud | AWS, Azure, Google Cloud |
| Infrastructure as Code | Terraform |
| Orchestration | Kubernetes |
| Monitoring | Prometheus, Grafana |

**Career paths:** DevOps Engineer, Cloud Engineer, Platform Engineer, Site Reliability Engineer (SRE).

## 6. Key Takeaways
- UI/UX design improves usability and accessibility.
- Software architecture organizes system components.
- AI engineering builds practical applications using AI.
- QA engineering helps prevent defects and improve quality.
- DevOps improves collaboration, automation, deployment, and reliability.
